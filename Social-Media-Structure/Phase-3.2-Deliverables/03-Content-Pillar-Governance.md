# Phase 3.2 Deliverable 03 — Content Pillar Governance

**Status:** Working document

## Before approving a content idea

Confirm that it:

- Serves one primary pillar.
- Creates a specific audience realization.
- Supports the approved CMS positioning.
- Has an appropriate funnel role.
- Uses a defensible evidence level.
- Avoids unsupported results claims.
- Leads to a proportionate CTA.
- Does not turn CMS into a generic content-production provider.

## Evidence labels

- **Approved finding:** May be stated as a CMS strategic position.
- **Research-supported assumption:** Must be framed with appropriate caution.
- **Working hypothesis:** Must be tested and must not be presented as universal truth.
- **Unverified claim:** Exclude from formal CMS content.

## Routing rule

If an idea is mainly about platform mechanics, posting cadence or platform-specific execution, route it to Phase 5. If it is mainly about funnel sequencing and conversion movement, route it to Phase 4. If it defines the strategic meaning and role of content, keep it in Phase 3.
